# Introdução aos Loops em Python 🐍

Este repositório contém uma coletânea de exemplos práticos sobre **estruturas de repetição (loops)** na linguagem Python. O objetivo deste material é servir como guia de estudos para iniciantes em programação.

## 📚 Tópicos Abordados

No arquivo `AulaLoops.py`, você encontrará exemplos comentados e práticos sobre:

* **`for` loops:** Como iterar sobre listas, strings e utilizar a função `range()`.
* **`while` loops:** Uso de loops baseados em condições booleanas com atenção à atualização de variáveis.
* **Controle de Fluxo:** Implementação de `break` (para interromper a execução) e `continue` (para saltar iterações).
* **Cláusula `else` em Loops:** Entendimento de como o `else` se comporta em loops (execução apenas se não houver interrupção via `break`).
* **Loops Aninhados:** Prática de estruturas de repetição dentro de outras para lidar com dados bidimensionais.
